# 拉链快照模板（CHAIN SNAPSHOT · 六件套）
> 来源：HPE data/HPE/HPE_options_chain_52w_20260913.md 通用化（#82 铁则已含）。

1. **快照口径**：链源 URL + ts + 对应收盘日；与上次快照关系（新行情/扩覆盖/核验重拉）。
2. **标的 feed**：spot/bid-ask/volume 与官方 OHLC 互证（官方为锚，注明差异）。
3. **过滤**：iv=0、iv>上限、陈旧无报价行；OI<下限标「不采信」。
4. **到期总览表**：每个到期=类型/距today天数/月数/期限闸判定/ATM IV/流动性一句话。
5. **逐到期关键档**：bid/ask·OI·delta（feed δ=市场隐含概率，注明口径）。
6. **IV 期限结构表 + 事件溢价标注**（财报月单峰等）。
7. **方法与坑**（供下次复用）：拉取通道/分块数/**末块核验（必拉到 totalChunks 末块+最后到期符号）**/parity 抽查/已知数据源陷阱。

铁则：fetch 内容不持久 → 蒸馏数字必须当轮落盘本模板文件，Key Results 是唯一在册来源。
