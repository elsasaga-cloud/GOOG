# 数据字典

## 一、`data/<TICKER>/<TICKER>_N<行数>_chipdata.csv`（47 列）

由 `scripts/stock_data_sandbox.py` 生成。行 = 交易日（升序），数值保留 2 位小数，编码 `utf-8-sig`（Excel 直开不乱码）。

### 1. 基础行情（11 列）

| 列名 | 说明 |
|---|---|
| 日期 | `YYYY-MM-DD` |
| 开盘 / 收盘 / 最高 / 最低 | 复权价（yfinance `auto_adjust=True`） |
| 5日涨幅 | `(C − C₋₅)/C₋₅ × 100`，% |
| 振幅 | `(H − L)/前收 × 100`，% |
| 换手率 | `成交量 / 流通股本 × 100`，%；流通股本取不到时退化为「成交量/60 日均量」并截断至 [0,5] |
| 量比 | 成交量 / 前 5 日均量 |
| 成交量 | 股 |
| 成交额 | 收盘 × 成交量 |

### 2. 均线（21 列）

- **日线 MA**（10 条）：5, 15, 30, 45, 60, 75, 90, 105, 120, 150
- **周线 MA**（11 条）：5, 10, 15, 20, 30, 40, 50, 60, 70, 80, 90

周线按 `W-FRI` 重采样后计算，再用 `merge_asof(direction="backward")` 回填到日线——**同一周内的日线共享该周最近已完成周线值，不含未来信息。**

### 3. 筹码分布（8 列，日K 口径）

| 列名 | 说明 |
|---|---|
| 获利比例 | 成本低于当日收盘的筹码占比，%（越高越拥挤） |
| 平均成本 | 筹码分布加权平均价 |
| 90%成本-低 / 90%成本-高 | 剔除上下各 5% 后的成本区间 |
| 90%集中度 | `(高−低)/(高+低) × 100`，越小越集中 |
| 70%成本-低 / 70%成本-高 | 剔除上下各 15% 后的成本区间 |
| 70%集中度 | 同上口径 |

### 4. 衍生对比（7 列）

| 列名 | 说明 |
|---|---|
| 日K筹码平均成本 | ＝「平均成本」（250 日窗口） |
| 周K筹码平均成本 | 周线全历史衰减口径，回填至日线 |
| 日K筹码偏离率 | `(收盘 − 日K成本)/日K成本 × 100`，% ← **短线拥挤度核心指标** |
| 周K筹码偏离率 | 同上，周K 口径 ← **长线浮盈厚度** |
| 收盘价相对周MAX位置 | 收盘 vs 所有周线 MA 最大值的偏离，% |
| 日周筹码成本差值 | 日K成本 − 周K成本（>0 表示近期买盘成本抬升） |
| 日周筹码成本差值率 | 上者 / 周K成本 × 100，% |

### 5. 筹码算法参数

| 参数 | 值 | 含义 |
|---|--:|---|
| `NBINS` | 2000 | 价格网格分箱数 |
| 分布形态 | 三角分布 | 峰值在 VWAP（截断于 [Low, High]），向 High/Low 线性衰减 |
| `RANGE_D`（日K） | 250 | 滚动窗口，约一年 |
| `CHIP_K`（日K） | 1.0 | 换手衰减系数 |
| `WK_K`（周K） | 0.30 | 周K 换手衰减系数（抑制长周期换手累积过快） |
| `WK_MAXT` | 0.02 | 单周换手上限 2%（防异常放量吞噬历史筹码） |
| `WK_HL` | 100 周 | 半衰期，约两年 |

**递推公式：** `chip_t = chip_{t−1} × 时间衰减 × (1 − 换手率) + 当日三角分布 × 换手率`

> 日K 用固定窗口重算（反映一年内活跃筹码），周K 用全历史增量 + 半衰期（反映长线沉淀成本）。两者差值即「短线资金 vs 长线资金」的成本落差。

## 二、`data/<TICKER>/chip_scan_<YYYYMMDD>.txt`

由 `scripts/chip_analysis_sandbox.py` 生成的四维仪全文报告，8 个区块：

| 区块 | 内容 | 读法要点 |
|---|---|---|
| ① 13F 机构持仓 | Top10 持有人、股数、占比 | 关注是否有维权资本（如 Elliott）、被动 vs 主动结构 |
| ② Volume Profile 双周期 | 全局 + 近期两套筹码直方图 | **暴涨股必须以近期窗口为准**（见 METHODOLOGY 的口径警告） |
| ③ Anchored VWAP | 主锚 + 附加锚的 AVWAP 与偏离 | 主锚自动选「近 90 天内最后一个涨幅>8% 日」；跌破主锚＝离场条件之一 |
| ④ IV 结构 + Max Pain | 近月/次月/季度 ATM IV、偏斜、C/P、OI | **总 OI<5000 时 MaxPain 标 [OI不足]，不采信** |
| ⑤ 做空 + 内部人 | 做空占流通比、月度变化、内部人净额 | 内部人已过滤赠与/行权/缴税，仅留公开市场买卖 |
| ⑥ 相对强弱 | 30 天 vs 对照标的超额与 RS 趋势 | RS 转下降＝板块内部动能分化的早期信号 |
| ⑦ 财报日历 | 预估财报日与距今天数 | ≤7 天标警示；≤21 天为财报窗口期 |
| ⑧ 综合评分 | 五维加权 + 离场条件计数 | 分档见 METHODOLOGY |

### 评分函数速查

| 维度 | 输入 | 满分条件 |
|---|---|---|
| VP | 安全垫 gap% | >20% 得 90+ |
| AVWAP | 偏离 dp% × 时间折价 | >15% 得 90+；锚龄>90 天打 0.85 折 |
| IV | ATM IV + C/P 各半 | IV<20% 且 C/P>1.5 |
| 13F | Top10 占比 | >60% 得 90 |
| 做空+内部人 | 做空比例 + 内部人净额 各半 | 做空<2% 且内部人净买入 |

## 三、数据来源与已知局限

| 项 | 说明 |
|---|---|
| 来源 | yfinance（Yahoo Finance），仅限个人非商业用途 |
| 复权 | `auto_adjust=True`，历史价含分红拆股调整——**与券商未复权行情会有差异** |
| 换手率 | 用**总股本**近似流通股本（yfinance `fast_info["shares"]`），美股两者差异通常很小但非零 |
| 13F | 季度披露，天然滞后 45 天以上 |
| 期权 | 快照式，盘中随时变化；流动性差的到期日 IV 失真 |
| 内部人 | 依赖 Yahoo 的交易类型文本分类，非标准化表述可能漏判 |
| 财报日 | 「预估」性质，以公司官方公告为准 |
