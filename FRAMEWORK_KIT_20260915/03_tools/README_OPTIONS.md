## 文件说明

| 文件 | 用途 | 运行节奏 |
|---|---|---|
| `positions.py` | **持仓单一事实源**（股数/成本/在场期权/财报日历/门槛），改持仓只改这里 | 持仓变动时 |
| `quant_core.py` | 量化底座共享模块：State十均线/筹码(含周K锁仓)/GBM/HMM/GARCH/方向投票 | 被下面两个调用 |

| `satellite_quote.py` | 100股卫星仓三档报价 v5.0 | 想做正股波段时 |

## v3.0/v5.0 相对旧版的关键变化

1. **Playwright整体退役**：期权链改用yfinance API（bid/ask/OI/IV全字段，2026-08实测HPE完整可用），
   删除无头浏览器/Chrome路径/反检测脚本/表头猜列等全部脆弱环节
2. **Yahoo v7/quote价格源弃用**（2026-08实测401失效），卫星仓价格源重排为：
   yfinance fast_info → yfinance history收盘 → 手动输入(10秒超时) → Excel回退
3. **持仓感知**：引擎自动计算可备兑张数；CC可开=0时强制CSP并提示先buy-to-close
4. **裸CALL硬风控**（新增）：卫星仓卖出100股会让在场CALL75变裸卖——卖出侧自动降级"仅参考"，
   执行前必须先平CALL腿
5. 四脚本合并为二（v1.0 CC/CSP单独版废弃，逻辑全在引擎内）；权利金门槛按1张等比调整(15/30→8/15)
6. PART A量化逻辑（State/筹码/GBM/HMM/GARCH/投票）与原融合版v2.0完全一致，未改算法

## 硬风控清单（引擎内置，不可绕过）

- 财报±7天禁开新仓（在场持仓按作战卡处理，不强制平仓）
- 可备兑股数不足 → CC降级仅参考
- 卫星仓卖出导致裸CALL → 卖出侧降级仅参考
- 价格脱离70%筹码密集区 → 双向降级仅参考
- 获利盘>95% → 卫星仓买入侧降级
- 周五不开新仓；DTE≤1不开新仓；权利金<$15不执行
