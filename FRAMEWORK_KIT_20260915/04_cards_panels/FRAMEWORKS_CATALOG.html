怎么用：任何新会话/新 Agent/换标的库都先走这套加载仪式，保证零上下文损耗。移植时整文件照抄。

双 README 交接体系 🟢 直接移植AGENT-README.md ＋ HANDOFF.md

分工明确：AGENT-README 只管会话/任务/分支状态快照（任务表/等待中/commit 表/对话史）；HANDOFF 管深度交接（研究体系、用户规矩、更新 SOP、当前状态 §六）。两者并存不互替。

怎么用：每轮对话结束或阶段完成必须更新；时间戳+更新由+最新口径三件套同步。移植时复制骨架、换内容。

决策日志双轨制 🟢 直接移植journal/decision_log.md（#1-#31）
