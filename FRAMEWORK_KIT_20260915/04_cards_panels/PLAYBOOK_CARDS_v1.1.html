§0 卡是什么、不是什么 Ground Rules

卡是 ✅卡不是 ❌
执行层压缩：查卡→对判据→动手→留痕不是研究替代品——论点变化必须回 thesis，不改卡
跨标的可复制结构（🟢部分原样用，🟡部分填槽）不是参数本身——槽位里的数字永远属于单个标的
有失效条件的活资产（挂靠 logic_baseline diff）不是永真公式——regime 变了先过老化处置卡（卡G）

§1 执行卡（转正自 Backlog） Execution Cards

卡A · 极端日做 T SOP Backlog① 转正🟢 结构🟡 触发参数填槽

恐慌日的机械动作：触发双条件 → 买 100 股 → ATR 挂单 → 卖压回 → 结算留痕。
环节内容
触发（当日盘中）单日跌幅 ≥ -7 ~ -8 %，或 跌破 MA30 且恐慌放量 —— 满足其一即进入待命，不立即动手
动作买 100 股卫星批（只动库存批，永不卖底仓）；挂单价 = 现价 − 0.5×ATR14（执行层挂策略单，价位+ATR）
卖出反弹至挂单锚 A_up 卖出；若带内可搭 ATM Call（溢价 ≥ $1.00）
禁区横盘区间日内 T（HPE 例：52-54）；追强势反弹（HPE 例：55+）；财报窗 ±7 天；跌破停手线（HPE 例：<45.70）双侧停手
结算留痕wheel_log / decision_log 记一笔：触发条件、成交价、对错判据

卡B · 生态/同行雷达节奏卡 Backlog② 转正🟢 方法全套

同行出新闻时唯一要回答的问题："这改我的节奏吗？"——只改节奏，不改论点。
环节内容
频率每轮研究必扫；财报季（窗口前后 ±7 天）加密到事件即扫
对象同行名单 = 🔴 标的专属参数（HPE 例：DELL/WDC/STX 类硬件同行），换标的必换名单
判定同行事件 → 归类：节奏类（订单/产能/价格战/指引时点）→ 只修正我的时序预期；叙事类（技术路线颠覆/行业逻辑重构）→ 升级到 thesis 层处理，雷达不裁决
输出一句话节奏 diff 记 decision_log（"X 事件 → 我的 Y 时点预期提前/推迟"），禁止在雷达层反向改论点
载体跟踪协议雷达节 · 约束 #33

卡C · 年度收益统计法 Backlog③ 转正🟡 方法可移植

给一只股票画"脾气画像"：全年单日收益分布，一切振幅类参数的母矿。
  1. 拉日线全史（行情锚=官方 OHLC，约束 #30；口述成交只覆盖用户自身）
  2. 算日收益序列 → 分年度统计：中位 / P75 / P95 / 极端尾
  3. 分层标记 regime（如 HPE：2021-25 常态 vs 2026 翻倍期）——不许用混年期参数
  4. 输出画像卡：常态振幅带、极端日频率、尾部深度
  5. 喂给下游：振幅锚（A_up/A_dn）、做T触发校准、CSP 门槛与实现波动互证

重跑触发：每年初 1 次 + regime 疑变即跑（HPE 判例：#30 发现 2026 振幅 2-3 倍 → 全家参数重算）。载体：#16 年度收益报告。

卡D · 参数资产复职重参模板 Backlog④ 转正🟢 模板通用

任何参数类资产过期后走这三步复活——不达标就继续躺着，不勉强。
  1. 重算：选定新数据窗（近 N=45 日 or 新 regime 分层）→ 按原公式重算参数对 A_up / A_dn → 用新参数回测近 5 日，胜率 > 55% ？
  2. 重分配角色：参数对上游给卖出定价（CC 参考）、下游给挂单微调——触发类判据不动（只修锚，不改扳机）
  3. 恢复资格：胜率达标 → 恢复报价资格；不达标 → 继续降级，标注"待下一个 regime"

留痕：全程 decision_log（判例 #30：薅羊毛玩法①从降级到复职三步首用）。适用：任何标的、任何🟡参数类资产。

任何玩法跨标的移植前的强制安检门：五项逐个打 ✓/✗，全过才动手。
前提问题打分（换标的时填）
P1标的有底仓价值吗？（不归零、值得长期持有 β 仓）✓ / ✗
P2期权链流动性够吗？（OI、价差、月权/周权齐全度）✓ / ✗

卡F · 新股冷启动 8 步 Checklist 🟢 模板通用

换标的时的标准动线：从空目录到首笔计划内动作。
  • ① 建库：宪法 + 双 README + decision_log / logic_baseline 双轨建档（照抄目录卷 §②）
  • ② thesis + 破坏条件成文（🔴 从零研究，禁止复制他股论点）
  • ③ 量化体检：跑卡C 年度收益统计法 → 脾气画像
  • ④ 拉链：链上侦察 SOP 首拉 → 快照建档（跟踪协议 §六）
  • ⑤ 阶梯 + 窗口：档位带、窗口制、门槛线全填新参数
  • ⑥ 账本：wheel_log 建档，首笔动作必须是计划内（查 7 档/卡A）
  • ⑦ 雷达：卡B 同行名单换新、节奏基线定档
  • ⑧ 首笔计划内动作 + 对错判据留痕 → 冷启动完成

卡G · 资产老化处置卡 🟢 流程通用

资产的体检-降级-复职-退役全流程——保证家产永远翻新而不是悄悄失效。
状态进入条件动作
在役判据全绿正常使用；每轮 logic_baseline diff 体检
降级参数与实况偏离（HPE 判例：振幅锚差 2-3 倍）或可靠性存疑标注"参考器"，禁止作为主判据 → 转卡D 复职
复职卡D 三步走完且小样本验证达标恢复原角色，decision_log 记复职日
退役复职两次失败 / 前提消失（HPE 例：IV<30% 引擎退役）归档不删（历史只增不删），载体标注已退役

探测器：logic_baseline 每轮 diff + 卡C regime 统计。判例：#30 全流程首用。

卡H · 机构观点三角验证卡 用户自有框架 · v1.1 入册（#41）🟢 结构🔴 样本内容逐标的重建

三层降噪结构（独立第三方 60% / 卖方过滤 40% + 辅助验证 + 分档执行）+ 仓库对账五关——长期持有者"来回搞"机构观点的标准姿势。
流程内容
① 独立层 60%DCF/独立研究：纳入标准=90 天内更新/方法透明/有假设/有跟踪记录；剔除过旧与噱头样本
② 卖方层 40%PT/评级过滤后统计（P25/P50/P75）；长期机械唱多/唱空者剔除
③ 综合+辅助加权结论；仅分歧大时启用技术面/空头/期权/高频基本面验证
④ 仓库对账五关
（入库门，本卡核心增量）		时点关：每条带日期、与库比新旧，旧数据不进"最新"表（判例：WF $67[6/18] vs 库 $54[9/4]）｜ 口径关：PE 年份/单位/MA 窗口/IV 定义（判例：FY26 11-20x vs 判据锚 FY27 11.6x）｜ 实测关：能用市场价复现的才算数（判例：$1.30 的 9/18 P50 只有 IV≈55% 能复现，37% 只值 $0.70）｜ 归属关：数字-机构绑定要稳，漂移即存疑（判例：SWS 65.56 vs 84）｜ 叙事关：方向可同向采信，倍数迁移类叙事不入判据（判例：25x）
⑤ 执行五关全过 → 升级"可执行证据"；否则只入"参考堆"；分档触发仍走本标的阶梯+跌因闸

频率：季度 / 财报后 / 12/2 前。首用判据：连续两次五关通过率 ≥80% → 升级为雷达常规源。首案：#41（HPE 2026-09-08：方向同向✓；期权层与技术面两处硬矛盾出局；四处时点漂移）。
