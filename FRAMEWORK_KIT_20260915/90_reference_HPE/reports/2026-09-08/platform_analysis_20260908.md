# 平台判定：45-50 是"已完工的旧平台"，新平台候选在 52-55（2026-09-08）

> 触发：用户观察"从 0728 开始现价 P 和 MA60 逐渐接近重合，持续快 1 个半月，就是 45~50 的价格——这会是一个新的平台吗？"
> 数据：N1700 chipdata 实测（止 8/14，含内置日MA60 列）；8/15-9/8 用库内官方锚（9/2 收 51.83 / 9/3 收 54.44 / 9/4 收 52.00 / MA60 49.69 / MA20 54.42）+ 用户口述成交（8/18 买 55、9/3 T 46.88/51、9/8 卖 54）重建。行情锚=官方 OHLC（约束30）。

## 0. 结论先行

1. **校准一（收敛极点）**：P 与 MA60 最近的一次不是"重合"而是 **7/29 偏离 +3.5%**（收 44.44 vs MA60 42.93）——全程 MA60 从未上穿价格、价格从未收在 MA60 下方（最小偏离 3.5%）。"接近重合"实为 7/20-8/2 两周窗口，极点 7/29。
2. **校准二（平台与时长）**：45-50 的准确核心带是 **44-48**（收盘口径 43.71-50.24），平台期 = **6/26-8/2 约 5 周**（不是 1.5 个月连续——8/3-8/14 价格已离场去 63 一带）。用户体感"45-50 平台"成立，时间跨度按数据修正。
3. **判定：45-50 = 已完工的旧平台（上升中继型）**。教科书级"以平代跌"：6/2 冲 64.06（52周高区）后，价格横住 5 周（44-48），**MA60 从 36 爬到 43.9 穿越上来**——时间换空间的吸筹形态，比回调洗盘更强。
4. **它已经当过两次发射台**：8/3 收 50.24 破箱顶（8/12-13 量比 1.48/1.62 放量确认）→ 8/13 高 63.44；回踩 8/14-9/1 守住箱顶上方（9/2 收 51.83，未回箱）→ 9/2-9/8 第二腿 54 一带。
5. **新平台候选 = 52-55（当前运行区），正在成形、未确认**：底=旧箱顶残留 50-52 + MA60 49.69 + 筹码密集区上沿 三重共振带（50 线=§3 四重共振之下沿）；顶=MA20 54.42。确认判据：未来 2-3 周收盘横住 52-55 且 MA20 走平上翘；**失效判据：收盘跌回 50 下方（R8' 双条件已覆盖）**。
6. **操作零变更**：阶梯/引擎参数全部不动——但平台证据让三条既有线**咬合更紧**：一档 47.8-50=旧平台核心（回踩埋伏逻辑成立）、strike≤50 生命线=箱顶结构位、R8'=平台失效线。

## 2. 判定逻辑（预注册标准）

- **平台成立**：≥15 交易日收盘落于箱体、箱宽 ≤15%、期间 MA60 单向爬升穿越箱体 = ✅（6/26-8/2 全满足：26 交易日、43.71-50.24 宽 14.9%、MA60 +7.8 单向）
- **平台性质**：MA60 从下方穿越+价格不破 MA60 = 吸筹中继（非派发）✅；8/12-13 放量破顶 ✅
- **旧平台现状**：已转换为"下方吸震层"——8 月中回踩与 9/2 回踩均未触及箱顶 50；一档 47.8-50（阶梯）= 回踩旧平台核心的埋伏区
- **新平台候选（52-55）确认判据**：未来 2-3 周收盘主体落于 52-55 + MA20（54.42）走平上翘 + 缩量横盘；**失效**：收盘 <50（箱顶失守，回旧平台区，一档挂单接管）——R8'（收盘<49.69+爆量阴线）为硬失效双条件
- **量度目标**：旧箱体高 50−44≈6 → 第二腿量度目标 ≈ 50+6=**56 区**；首个整数磁钉 **55**=C55 OI 墙 13.1k + MA20 上方 = "追 55+" 铁禁区线（体系早已把超额区圈掉）

## 3. 四重共振：50 这条线为什么这么硬

四套互不相干的逻辑指认同一条线——这就是体系当初把 50 定成生命线的后验解释，也前瞻支撑了"回踩 50-52 = backbone 主战场"（7 档表既有档）。

## 4. 对操作的含义（判据零变更）

1. **一档 47.8-50 挂单的语境升级**：不只是"阶梯折扣"，是"回踩已完工平台核心"——若新平台失效回落，这里是第一承接区（跌因闸照旧）。
2. **backbone strike≤50 的结构理由 +1**：卖的是平台顶支撑带，不是随机数字。
3. **若确认新平台 52-55**：长期层语境（折价 13-20% 收敛中）+ 7 档表 ≥54.42 档（持有不追）继续管辖；55 上方 = 铁禁区不追。
4. **若失效回落 <50**：R8' 看双条件；一档接货；引擎照窗口制。
5. 平台观察挂 logic_baseline 语境、入 decision_log；每轮 diff 时补一眼"52-55 横盘判据"进度。
