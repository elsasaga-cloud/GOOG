# AAWS 移植评估：PFE 体系能否装到 HPE 上（2026-09-05，#26）

> 背景：用户沉淀了一套 PFE 上的 AAWS（Active Anchored Wheel System，锚定标的主动轮动期权体系）：现金担保卖 ATM/轻ITM 短期 PUT（末日+7-10天双周期 2+2 角色互换）、行权=接货、三态模型决定接货股回卖（R=(S−P)/M≤L×M 卖，否则等）、周三开仓周五结算、不依赖 CC、分红+时间兜底。问：能否移植 HPE。
> 结论先行：**能装，但不能 1:1 抄——HPE 是"重装版"：权利金厚 2-4 倍、波动大 2-3 倍、股息地板几乎没有。移植=把既有阶梯（#23）+CSP 纪律（#21）升级为周度轮动引擎，行权红线从"≤26"翻译为"净接货 ≤50"。**

## 4. 合成：HPE-AAWS = 阶梯的执行引擎

```
backbone（月权槽）：= 既有 CSP 纪律原样（P50 / 净basis≤50 / ≥$2.30 / 11/20 后黑窗自然停）
rotator（周权槽） ：把"47-50 挂单等"升级为"带内收租等"
                   └ spot≤50 才开 → 行权=一档成交（且更便宜）→ 三态模型管退出 → 资金回流
两槽共用现金池，行权总股数并入阶梯口径（窗口内 ≤400 路线），底仓 200 永不参与
```

与既有体系零冲突：阶梯（#23）管**规模与闸门**，AAWS 管**接货方式与周转**；三道闸（T1-T5/跌因甄别/窗口制）**优先级高于引擎**——闸门一响，引擎先停。

## 5. 四个不能照抄（诚实段）

1. **股息地板幻觉**：PFE 的"被套=收 6% 租"在 HPE 不成立（1%）；HPE 的熬靠论点层——论点变色时周权会照样把你接在下跌路上，所以三道闸＞引擎
2. **2 年箱体幻觉**：45.7-64.25 只有 3 个月历史，7/28 型单日 -9.8% 可以让周权一夜从带外变带内——**strike≤50 是生命线不是偏好**
3. **旧数字全部作废**：文档里 43.98/800 股/CC46 那组是 6 月缺口前的示例，已按 52 现值全部重算
4. **张数纪律**：PFE 每周 3-4 张的前提是 2-3% 波动；HPE 两槽起步，跑顺一个月后要不要加倍=用户改参（#23 的 2 张口径之上需重新拍板）

# v3 增补（同日，#30）：双玩法可靠性判决

## 决定性证据：波动 regime 已变（N1700 全史振幅统计）

## 判决一：正股卫星仓 v5.0（薅羊毛玩法①）——逻辑可靠，参数过期，降级为参考器

- **逻辑层 ✅**：不追价/事件避让/月 3 轮限额/卖前查 CC——这些基因永不过期
- **参数层 ❌**：振幅锚取自 3000 天分布（主体=中位 2-3% 时代），在当前 6.4% 中位的 regime 里，三档报价系统性贴太近——卖档 +3% 在 6.4% 日振幅里是噪音内，买档同理。**筹码区逻辑也大概率卡死**：YTD+124% 后获利比例贴 95%+ 上限，买侧几乎永久硬阻断
- **样本层 ⚠️**：人工版战绩 2 胜 0 负（#7 +$120、#17 +$412），脚本版在当前 regime 零实盘
- **处置**：若要用，先重校准——振幅分布只取 2026 年数据（或直接用 ATR14 实时值）重算 A_up/A_dn，再跑三档；其核心职能（低吸高抛）已被阶梯+AAWS 吸收，不重校准就只当"行情坐标仪"看，不当"报价机"用

## 判决二：HPE-AAWS（期权轮动玩法②）——单笔无优势，结构可靠

- **诚实的单笔账**：周权租 $0.4-1.0（行权价的 0.8-2%）vs 单日 -5% ≈ $2.5-2.75 穿带——**每周期 edge 薄于单次事件风险，这不是高胜率游戏**
- **可靠性来源=结构五件套**，不是胜率：①strike≤50 生命线（被行权=阶梯一档成交，**接货即计划**，损失事件被改写成计划事件）②窗口制（11 月下旬清场，二元风险不跨季）③三态 L=0.2（库存不恋战）④三道闸＞引擎（论点变色先停人）⑤停手日历（黑窗/Dell 周/IV<30%）
- **定价已验证**：IV 55% 市场价 ↔ 当前 6.4% 日振幅的实现波动，互相印证——引擎参数从 9/5 实链取的，不是旧 stats
- **样本层 ❌**：零实盘轮 → 用 #26 的 8 周判据去挣信任（≥75% 周正现金流+零 basis>50 违规，达标才议加倍）
- **失效信号**：basis>50 成交 1 次=违规、2 次=停引擎；8 周 <75% 停；IV<30% 租金退役；三支柱翻红立即停

## 可靠性层级（最终答案）
