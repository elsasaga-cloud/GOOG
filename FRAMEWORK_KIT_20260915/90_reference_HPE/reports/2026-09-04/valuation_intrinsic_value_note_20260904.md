> 用户问题：①"其实还是 50 以下买、CSP 行权价 50 以下为准是吧？" ②"从深度估值/内在价值分析，它就值 50 还是啥？"
> 数据底座：深度调查 `reports/HPE/2026-09-03/deep_dive_all_frameworks_post_q3_20260903.md` ⑦-①（$49≈FY27 P/E 10.7-11.1x + FCF yield 7.5%、市值~$66B@49、股数~1.36B、下行锚 11x×$4.10≈$45、共识 PT $69.44）

## 结论

- **内在价值中枢 ≈ $60-65**（13-14x FY27 EPS $4.50 中值 / FY27 FCF yield ~6% / DCF base）；**bear ≈ $44-48**（= 第二档数学：11x×$4.10≈$45）；**bull ≈ $67-72+**（15x + AI 溢价）；共识 PT $69.44（财报后重估中，判据：中枢 ≥$65 存活）
- **$50 ≠ 价值**。$50 = 三个独立坐标的巧合交汇：① MA60 $49.44（趋势成本线）② 9/3 天量换手区上沿（筹码密集）③ FY27 P/E ~11x + FCF yield ~7.4%（深度价值入场线）——是"买得漂亮"的价格，非"它值"的价格
- **CSP 判据精确化：看净接货价（K−权利金）≤50，非行权价名义 ≤50**。Oct P50 basis≈47.5 带内；权利金够厚时行权价贴 51-52 亦可（#12：P52 净 basis 49.36 曾判"带内上沿"）。锚=净接货价落回 47-50
