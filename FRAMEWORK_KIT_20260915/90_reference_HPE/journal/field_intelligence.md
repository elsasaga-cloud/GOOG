# HPE 一线行业情报日志

> 用户在工作中接触 HPE 较少，但具备交换机/通信行业基础并持续研究 HPE。本文件是可选记录模板：有接触就记录，没有就留空，不为了填表制造信息。现场信息是线索，不直接替代财报和公开数据。

## 记录模板

```text
日期：
信息来源/接触场景：
产品或项目：
客户类型/地区：
涉及厂商：
HPE是否参与：
最终结果：
赢/输原因：
信息可靠等级：A/B/C/D
影响论点：T1/T2/T4/H1/H3/H4
是否需要外部交叉验证：
对下一季的判断：
```

## 使用纪律

- 单一项目不能推导全市场份额；
- 不记录客户机密、个人信息或受保密协议保护的内容；
- 事实、个人判断和猜测分开写；
- 每季将重复出现的信号与 HPE 财报数据交叉验证；
- 若现场情报与财报冲突，先标记为待确认，不立即改变 T1-T5 状态。
