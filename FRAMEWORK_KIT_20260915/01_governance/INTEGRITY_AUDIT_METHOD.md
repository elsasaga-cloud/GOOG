# Agent 完整性审计双轮法（v1.2 新增；"确保都入库"的标准动作）

## R1：内容对账（知识点 grep 法）
1. 把要确认的讨论拆成**知识点清单**（数字/术语/原话片段各取关键词，≥30 点为宜）
2. 逐点 `grep -rl <kw> --include="*.md" --exclude-dir=.git --exclude-dir=archive .` → 记录命中文件数
3. 未命中=遗漏，当场补档；全命中=出对账表（知识点→位置映射）存档
4. 口径=现行库（archive 豁免）；历史行旧表述按"只增不删"保留不算错

## R2：时效与衔接（四角度，R1 全过后做）
| 角度 | 方法 | 抓什么 |
|---|---|---|
| 数字反验 | 新数据文件验行数/重复值/尾行日期 | 统计口径错 |
| 过期字样扫描 | grep 旧 SOP 术语（如已升级的件数词）/旧"待补"标记 | 文件改了引用没改 |
| 在途仓位检查 | 逐笔未平仓动作找台账 | 漏账 |
| 冷启动模拟 | 按宪法首读协议走一遍（README→状态→规范→HANDOFF→git log） | 衔接断点 |

## 修复规范
- 过期字样=**原地 additive 注记**（不删原文）：`【#NN 已升级/已补录 → 新位置】`
- 关系不明=显式声明（如两套相似档位的适用场景）
- 疑似漏账先核查再定性（可能已闭环在别处）；误删风险动作=禁止

## 输出
审计报告存 reports/（R1 对账表+R2 发现处置表+残余待办清单——**"待"字头=显式未决有归属，非遗漏**）+ decision_log 一笔 + 双 README/HANDOFF 指针刷新。
